## Context

Antigravity (`agy`) loads user-global instructions from `~/.gemini/GEMINI.md`.
The Prompt Refinement Protocol defined in `GEMINI.md` intercepts non-slash-command prompts to select a role and ask clarifying questions.
KoRewrite requires immediate text transformation without interactive prompt refinement or conversational turns.
`GEMINI.md` contains an explicit bypass: "If the request includes a slash command or is an investigative question, bypass this protocol."

## Goals / Non-Goals

**Goals:**
- Prepend `/rewrite\n\n` to the composed prompt payload generated by `PromptBuilder`.
- Ensure `agy` bypasses the Prompt Refinement Protocol and processes the text rewrite immediately.
- Update test cases in `PromptBuilderTests` to verify the `/rewrite` prefix.

**Non-Goals:**
- Modifying the user's `~/.gemini/GEMINI.md` global configuration file.
- Changing `AgyRunner` subprocess execution or timeout logic.

## Decisions

### Decision 1: Prepend `/rewrite` in `PromptBuilder.buildPrompt`
- **Approach**: Add `/rewrite\n\n` as the first line of the prompt payload before `[System Directives]`.
- **Rationale**: `PromptBuilder` is the centralized pipeline component for prompt assembly; modifying it ensures all CLI and Service invocations automatically benefit from the protocol bypass.
- **Alternatives Considered**: Prepending in `AgyRunner` was considered, but rejected because prompt composition responsibility belongs strictly in `PromptBuilder`.

## Risks / Trade-offs

- [Risk: Target model might output the `/rewrite` token in response] -> Mitigation: The prompt's `[Output Instructions]` block explicitly commands outputting only the rewritten text directly.
